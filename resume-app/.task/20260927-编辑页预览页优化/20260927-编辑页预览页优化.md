## 2. 已确认决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| B2 修法 | **先在模板详情页提交 ADD，拿到主键后再进编辑页**；失败留在详情页，按钮回「使用模板」 | 用户报的原始问题：先跳页再提交，失败后停在编辑页没有意义 |
| 编辑页 `?new=1` / `?template=` | **删除该分支**：编辑页只负责「编辑一份已存在的简历」（`?id=` / 无参续编辑最近一份），新建唯一入口 = 模板详情 | 后端 ADD 必须带 `templateCode`，编辑页自己造草稿再落库本身就是把创建动作放错了位置 |
| B3 修法 | 载入失败 / 简历不存在 → 错误态 + 重试 + 去模板库，**不新建**；确实一份简历都没有 → 空态引导去模板库 | 用户点的是具体简历，失败时不能替他做「新建」的决定 |
| B4 修法 | 小程序端选图后压缩 + 读成 base64 存进 JSON；超过 1.2MB（base64 长度）提示换图 | 后端没有上传接口，而 JSON 是唯一通道；base64 同时解决「重启失效」与「导出无头像」 |
| U6 修法 | 在 `style/index.scss` 定义一次 `--wot-color-theme: #2563eb`，把硬编码 `#0957de` 全部换成 `var(--wot-color-theme, #2563eb)`；页底统一 `#f5f6f8` | 该变量此前全仓没有任何地方定义，fallback 各写各的；定义一次即可让编辑页与三页同色 |
| P3 修法 | 后端 `UserResumeVO` 增加 `templateCode`，前端 `loadResume` 回填 `currentTemplateCode`，换模板时 UPDATE 也回传 `templateCode` | 后端表本来就有 `template_code` 列，只是没回传；不回传会导致换完模板下次进来高亮还是旧模板 |
| P4 修法 | **撤销虚拟渲染**：整份渲染所有页；滚动位置只存普通变量、不回写 `scroll-top`；回到顶部改用 `scroll-into-view` | 滚动中增删节点 + 受控回写正是 P6「疯狂抖动」的根因，稳定性优先于省节点 |
| P5 修法 | `ResumeRender` 增加可选 `minHeight`，预览页传 `pageCount * 1123px` | 双列底色靠容器高度撑开，最后半页也能铺满 |
| P7 修法 | 量高时摘掉 `minHeight`（`measuring` 标志），量到的才是内容自然高度；整理与还原期间全程保持摘掉 | 否则量到的是「页数 × A4 高」，页数越多量出来越高，整理永远判成装不下 |

## 3. 技术方案

### 3.1 时间格式化（B1）

`formatDate` 的每个值都先过 `isValidYmd`：合法 `YYYY-M` 走 dayjs 格式化，其余（`至今`、`2021年`、空串）原样返回；数组分支里开始 / 结束分开处理，只有一端时只输出那一端。`experience.vue` 保存时再补两道校验：勾「至今」但没选开始、结束早于开始，都 toast 拦截。

### 3.2 创建流程（B2）

新增 `store.createFromTemplate(templateCode)`：调后端 ADD，成功后 `upsertBrief` 并返回摘要。模板详情页按钮改为 `creating` 态（文案「创建中…」+ 禁用），成功后 `navigateTo('/pages/edit/index?id=<新主键>')`，失败留在详情页（错误提示由 http 层 toast）。

### 3.3 编辑页载入（B3）

`onLoad` 拆成 `load()`：

- 有 `?id=`：`loadResume(id)` 失败 → `loadError = '简历载入失败，请重试'`；返回 null（后端没有正文）→ `loadError = '这份简历不存在或已被删除'`。
- 无 id：`fetchList()` 失败 → `loadError`；列表为空 → 空态（去模板库）。
- 载入中 → 骨架屏（复用三页的 `skeleton` + `skeleton-pulse` 约定）。
- 错误态 / 空态 → `state` + `state-title` + `state-desc` + `retry` 约定（同首页）。

### 3.4 保存反馈（U1）

store 增加 `saveState: 'idle' | 'saving' | 'saved' | 'error'`，`saveCurrent` 三处赋值。编辑页顶部加一行白底标题栏：左 = 简历名，右 = 保存态文案（已保存 / 保存中… / 保存失败，点击重试）。

### 3.5 删除保护（U2 / U4）

编辑页与模块管理共用一个 `confirm` 弹窗：删条目、清空正文、删模块都先确认。

### 3.6 视觉规范（U6）

`style/index.scss` 的 `page` / `:root` 定义 `--wot-color-theme: #2563eb`；`editor-form.scss`、`editor-sheet.scss`、`RichTextEditor.vue`、`StyleSheet.vue`、`ModuleManagerSheet.vue`、`ModuleSettingSheet.vue`、`experience.vue`、`basic.vue`、`index.vue`、`preview.vue` 的硬编码主题色换成 `var(--wot-color-theme, #2563eb)`；页底统一 `#f5f6f8`；`uno.config.ts` 的 primary fallback 同步成 `#2563eb`。

### 3.7 预览页（P1 / P2 / P4 ~ P7）

- 分页：全量渲染 `pageCount` 页（**不做虚拟渲染**）；`onScroll` 只把 `visiblePage` 写进普通 ref，**不回写 `scroll-top`**。
- 页码指示：右下悬浮胶囊显示 `visiblePage / pageCount`，点一下回到顶部（`scroll-into-view="pageTop"`，500ms 后清空；不用受控 `scroll-top`）。
- 整理成一页可还原：记住整理前的 `IFitBase`，再次点击走 `applyFitScale(base, 1)` 还原。
- 底栏按钮加进行中 / 禁用态：导出中、整理中禁用重复点击；导出用 `uni.downloadFile` 的 `onProgressUpdate` 显示进度。
- 当前模板高亮：`activeTemplateCode` 初值取 `store.currentTemplateCode`（后端已回传）。
- 双列底色：`ResumeRender` 增加 `minHeight` prop，预览页传 `pageCount * PAPER_HEIGHT`。
- 整理量高：`measuring` 为 true 时 `ResumeRender` 不接 `minHeight`，量到的才是内容自然高度（P7）。

## 5. 验收标准

1. 未选开始时间就勾「至今」：编辑列表、简历正文、导出 PDF 都不再出现 `Invalid Date`。
2. 模板详情点「使用模板」：先创建成功再进编辑页；创建失败留在详情页可重试。
3. 带 `?id=` 载入失败 / 简历不存在：编辑页显示错误态 + 重试，不产生新简历。
4. 小程序端换头像后重启：头像仍在；导出 PDF 有头像。
5. 编辑页进入有骨架屏；保存失败有可见提示且可重试。
6. 删条目 / 清空正文 / 删模块都有确认。
7. 编辑页与三页主色、页底一致（`#2563eb` / `#f5f6f8`）。
8. 预览页有页码指示、回到顶部；导出 / 整理有进行中态；整理可还原。
9. 预览页往下翻到底不再抖动；右下角页码跟随当前页；点页码能回到顶部；双列模板第 2 页起左栏底色不断。
10. 「整理成一页」能真正完成：装得下时压进一页并提示成功，装不下时还原并明确提示；再次点击可还原样式。
11. 门禁全绿：`type-check` / `lint` / `test:run`（59/59）/ `build:mp-weixin`；后端 `mvn -q compile`。
