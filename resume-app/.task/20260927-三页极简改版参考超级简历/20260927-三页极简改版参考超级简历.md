## 背景

- 上一轮「对标 temp」（见 `.task/20260925-简历页面布局样式对标temp/`）把三页做成了蓝底渐变 hero + 主题色光晕 + 大圆角卡片，视觉偏重。
- 本次改为极简排版：浅灰页面底 + 白底内容块 + 细分隔线 + 单色主色（只给按钮/选中态/链接），字号层级收敛，圆角统一 6–8px，去掉全部渐变与装饰元素。
- 数据全部来自后端（`/resume/template/page`、`/resume/template/detail/{code}`、`/resume/page`），因此加载态必须显式可见。

## 设计规范（三页统一）

- 页面底 `#f5f6f8`；卡片/栏 `#fff`；分隔线 `#eef0f3` / `#f2f3f5`
- 文字：主 `#1f2329`、次 `#646a73`、弱 `#8f959e`、箭头 `#c9ced6`
- 主色 `#2563eb`，只用于按钮、选中态、链接
- 导航栏统一白底黑字（`pages.config.ts` globalStyle），不再随主题色变化

## 加载动画约定

- 首屏无数据：骨架屏（`background-color: #e9ebee` + `skeleton-pulse` 1.2s 呼吸动画）
- 已有数据时刷新：顶部 2px 不定长进度条（`refresh-slide` 1.1s）
- 触底翻页：14px 环形 spinner + 「加载中…」，到底显示「没有更多了」
